# Grenze Gotisch

Unmodified variable Gothic font from [Google Fonts](https://github.com/google/fonts/tree/main/ofl/grenzegotisch).
Downloaded from `ofl/grenzegotisch/GrenzeGotisch[wght].ttf`. Distributed under the
accompanying SIL Open Font License (`OFL.txt`), which is bundled with the app.
The font is bundled locally and never fetched at runtime.
